# Ahmed Mooeez — Portfolio Website

A responsive personal portfolio website for Ahmed Mooeez, aspiring Data Analyst.

## Design direction
- Dark charcoal background with dark teal panels
- Turquoise accents and clean typography
- Responsive layout for desktop, tablet, and mobile
- Sections: Home, About, Skills, Projects, Journey, Contact

## Run locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a public repository named **AhmedMooeez.github.io** under the `AhmedMooeez` account.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Your website will be available at `https://ahmedmoeez.github.io/` after GitHub Pages finishes deploying.
